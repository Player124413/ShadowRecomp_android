# Contributing Guidelines

Thanks for being interested in contributing.
To keep things brief, here we go.

# The Obvious

- Be respectful, act nice to people
- Ensure your changes are well tested, clean and organized
- You must understand ***100%*** of the code you submit. No less.
    - Be prepared to explain yourself.

Be aware: There's no guarantee every PR will be merged.
If you want to work on something big or time consuming, open an issue, or reach out to us first to see if there's interest.

# We're all Living, Breathing, People

> [!NOTE]
> Please remember that ShadowRecomp was created and maintained by people in their spare time
> for no financial gain.

ShadowRecomp is human made by people, for other people.

## Issues, Pull Requests

> [!IMPORTANT]
> We expect every discussion, issue, pull request to be written, read, and reviewed by a human.

Fill in requested template info (OS version, release version, etc).<br/>
Do not dump hard to read, low-effort, arbitrary yapping.<br/>

***Communicate with your own words.***

## AI Policy

> [!WARNING]
> AI should not be used to generate contributions to this project,<br/>
> ***including code, art, images, video, audio, issue reports or pull requests***.


Usage of AI tools to communicate with the maintainers of this project is disallowed.

AI is often overly verbose & includes noise distracting from the main point.

## Acceptable Use Limits

- To help you understand this codebase.
- Temporary debugging code (Must not be committed)
- Reverse Engineering assistance
- Finding bugs and security Issues in your own code

***You must not copy-paste any responses/solutions***.<br/>

***Do not use AI for what you cannot do by hand.***<br/>


We treat code as art. Do not slop. Do not vibecode.<br/>
Please preserve the existing artists' integrity; you are painting on their canvas.<br/>
Thank you.

## No commits Authored/Co-authored by AI agents will be merged.

We have no intent to advertise `Claude`, `Copilot`, `Codex`, etc.

Each commit must be constructed, and organised by yourself.

In an easy to explain way.

Don't be lazy.

## About Code Contributions

You are expected to understand ***100%*** of the code you submit. No less.<br/>
Having hand-written code is the only (realistic) way we can semi-validate this.

If you are working on nontrivial code- be prepared to explain yourself.

***If you can't explain what your changes do and how they interact with the greater system without the aid of AI tools, do not contribute to this project.***

## Project Specific Rules

- **Don't commit original game assets/data**: We can't legally share these, they're not our copyright.
- **Do not copy original game code 1:1**: We once again, don't own the copyright. Replacing the code is OK- copying is not.
- **Consider the maintenance burden**: For example, if you want to add something we have no intent to maintain (e.g. a DX11/Metal port), you'll be expected to maintain it. (handle bugs, etc.)
    - Broken features with no maintainers will be removed.
- **Do not share proprietary material**: Do not read the Xbox SDK; reverse engineer it, or work with any other proprietary material that is not publicly available. ShadowRecomp is a [clean-room](https://en.wikipedia.org/wiki/Clean-room_design) implementation that used only CXBX-Reloaded as reference. We do not want any legal issues.
- Not interested in mobile ports.
